Billing Lifecycle

SOW → Invoice → Payment

Once a consultant is hired, the post-placement billing lifecycle kicks in. Vendors submit monthly timesheets, Stryker's hiring manager reviews and approves hours, the system locks the approved record, and generates a GST-compliant invoice. Payment follows Net 60–90 day terms via bank transfer.

Key Features Demonstrated

Duplicate CV Check
First-come-first-served candidate ownership. System flags if another vendor already submitted the same candidate.
CV Auto-Fill
Upload a resume and the system auto-populates name, contact, experience, location, and skills from the document.
Configurable Pipeline
CV Review → Interview R1 → R2 → Offer → Hired. Candidate-self-apply stages removed. Vendor-managed flow.
Timesheet Approval
Day-by-day hours grid with vendor vs client comparison. Stryker HM approves/rejects with comments. OT cap enforced.
GST-Compliant Invoicing
Auto-generated invoices from approved timesheets. CGST 9% + SGST 9% breakdown. Net 60–90 day payment terms.
Contract Lifecycle Tracker
Per-consultant SOW → PO → Joined → Timesheet → Invoice → Paid progress visualization on the dashboard.
